# 港美股行情源：调研结论

2026-08-19 在一条分支上做过港美股行情接入（后废弃：main 9 月以嘉信官方行情 + Yahoo 兜底的
另一套设计做了美股，见 [DESIGN.md](DESIGN.md) 与 [RESEARCH-SCHWAB.md](RESEARCH-SCHWAB.md)）。
这里只留下那次调研里**今天仍然成立**的结论，每条注明实测日期。
架构已与那条分支无关；港股的决定见最后一节。

## 1. 美股：免费源不等于延时

美股 Level 1 没有强制延时，2026-08-19 美股盘中同一秒并发请求 AAPL：

| 源 | 滞后 | 采用 |
|----|------|------|
| Yahoo `query1.finance.yahoo.com/v8/finance/chart` | 0–2.9 s | 兜底源（嘉信未登录时） |
| 新浪 `hq.sinajs.cn` | 1 s | 否 |
| 腾讯 `qt.gtimg.cn` | 21 s | 否 |
| 东财 `push2.eastmoney.com` | 本机 502 | 否 |

国内源技术上可用，不用是 May 的偏好（尽量不用中国的工具链），而且都是无文档、需要 Referer
头的逆向接口。

嘉信的报价**逐条声明**是否实时（`realtime`；这个账户 2026-10-09 读到的是 `true`，
`quoteType: NBBO`）。App 读这个声明：标为延时的报价在自选行、面板页脚、菜单栏提示里标出，
告警通知也会注明。Yahoo 不作声明，就不替它下结论。

## 2. 拼写

- **类别股**：嘉信写 `BRK/B`（`schwabctl quotes BRK.B` 报错，`BRK/B` 的报价、搜索、K 线都正常），
  Yahoo 写 `BRK-B`（`BRK.B` 是 404）。App 统一存嘉信的写法，问 Yahoo 时换成连字符、
  结果再换回来（`Venue.canonicalInstId`、`YahooWire.yahooSymbol`）。2026-10-09 实测。
- **Yahoo 批量报价接口已关**：`v7/finance/quote?symbols=A,B` 回 401（要 crumb + cookie），
  只能逐个请求 `v8/finance/chart/<symbol>`。2026-08-19 实测。
- **港股代码**（若将来做）：HKEX 五位代码以 0 开头的，Yahoo 要去掉首位得四位
  （`0700.HK` 正常，`00700.HK` 在 2026-08-19 是「200 + 全空字段」的假成功，
  2026-10-08 已变成 404）；不以 0 开头的五位代码原样。解码要看价格字段在不在，
  不能只看有没有 `error`。

## 3. 港股：暂不做（May 2026-10-09 定）

main 的行情层没有港股：`Venue` 只有 OKX 和嘉信，Yahoo 搜索只留美国交易所，内核日历只有
连续交易与美股两种。做港股要先定两件事，记在这里供以后用：

- **数据源**：Yahoo 免费，但按 HKEX 规定免费基础行情至少延时 15 分钟，盘中延时从没实测过
  （两次测都在港股收盘后）；uSMART（May 已开户，港美股，OpenAPI）实时，但签名规则在公开资料里
  有两种互相矛盾的说法（拼接 `Authorization`/`X-Channel`/`X-Lang`/`X-Request-Id`/`X-Time`
  与请求体后 MD5withRSA，或只对请求体签名），要 May 登录后提供签名章节或官方 SDK 才能写。
- **建模**：`Venue` 在 main 里表示「在哪交易」，账本、运行器、账户都按它遍历，只读行情的港股
  不能直接加一个 case——要么给交易路径声明一个子集，要么在券商之外加一条「上市地」轴
  （以后接 uSMART 同时做港美股也需要）。另有两件具体的事：港股午休 12:00–13:00 是交易所规则，
  要在一处声明（Yahoo 的常规时段 09:30–16:10 是一整段，午休的 1 分钟 K 线全是 null）；
  港股假期按农历，内核没法像纽交所那样按规则推。
- **先修配置容错**：`ConfigIO.load` 只要一个字段解码失败就整份退回默认值。任何新 `Venue` 值上线前，
  自选与告警要先改成逐项容错解码，否则旧构建读到新值会用默认自选启动、下次保存时覆盖真实配置。

## 4. Apple：没有

Apple 没有任何公开的股票行情 API 或 Framework，系统「股市」App 用的是不对外的内部聚合，
Apple Developer Program 也不含此项。查证过，不是可选项。
